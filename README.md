# Учебный центр «Профессионал»

Многостраничный адаптивный сайт вымышленной образовательной организации. Университетский проект на HTML5, CSS3, JavaScript ES6+, Bootstrap 5.3.3 и Bootstrap Icons 1.11.3. Без SPA, фреймворков, backend и обязательной сборки.

## Опубликованный сайт

[Открыть сайт на GitHub Pages](https://nikmet.github.io/professional-center/).

Репозиторий: [Nikmet/professional-center](https://github.com/Nikmet/professional-center). Файл `GitHub Pages.url` в корне проекта открывает опубликованный сайт в браузере Windows.

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` сохраняет обычную раздачу статических файлов. Для обновления сайта отправьте изменения в `main`; GitHub автоматически повторит публикацию. Снимки браузерных проверок и локальные журналы исключены из Git, текстовые отчеты сохранены.

## Запуск

Откройте папку `professional-center` в VS Code и запустите **Live Server** для `index.html`.

Либо при установленном Node.js выполните из папки проекта:

```shell
node tools/server.cjs
```

Откройте http://127.0.0.1:4173. Для остановки сервера нажмите Ctrl+C. npm install не требуется. Bootstrap, иконки, шрифты и фотографии находятся локально; сайт работает без подключения к интернету.

## Структура

```text
professional-center/
├── index.html                 Главная
├── courses.html               Каталог программ
├── about.html                 Об учебном центре
├── documents.html             Документы и сведения
├── contacts.html              Контакты и обратная связь
├── assets/
│   ├── css/style.css          Единая дизайн-система и адаптивность
│   ├── js/
│   │   ├── main.js            Навигация и просмотр документов
│   │   ├── courses.js         Массив программ, поиск, фильтры, modal
│   │   └── forms.js           Валидация и демонстрационная обработка
│   ├── images/                Шесть сгенерированных фотографий WebP
│   ├── documents/             Шесть демонстрационных образцов TXT
│   ├── vendor/                Bootstrap, Bootstrap Icons, лицензии
│   └── favicon.svg            Простая интерфейсная иконка Bootstrap
├── tools/
│   ├── server.cjs             Необязательный локальный HTTP-сервер
│   ├── build-pages.cjs        Необязательное обновление общих HTML-блоков
│   ├── check-site.cjs         Проверки в браузере для разработки
│   └── axe.min.js             Локальный инструмент проверки доступности
├── PRODUCT.md                 Контекст проекта для Impeccable
├── DESIGN.md                  Документация дизайн-системы
├── .impeccable/               Контракт интерфейса и результаты проверки
└── README.md
```

Каждый из пяти HTML-файлов — самостоятельная страница с собственной разметкой шапки, навигации, содержимого и подвала. Навигация присутствует в HTML. Поиск, модальные окна и формы требуют JavaScript; на странице курсов предусмотрена текстовая альтернатива для отключенного JavaScript. Поля форм включаются только после установки обработчика проверки: без JavaScript они отключены, чтобы браузер не отправил их обычным GET-запросом.

## Возможности

- 12 программ с направлением, описанием, часами, форматом и условной стоимостью.
- Поиск по части названия без учета регистра и различий между «е» и «ё»; фильтр по четырем направлениям, сброс, счетчик и пустое состояние.
- Bootstrap Modal с индивидуальными темами и результатом каждой программы.
- Переход из программы в контакты автоматически выбирает направление и заполняет тему сообщения.
- Валидация двух форм: имя, российский телефон, выбор направления и согласие. В полной форме дополнительно проверяются email и сообщение длиной 10–2000 символов.
- После успешной проверки поля очищаются, появляется честное сообщение об отсутствии отправки.
- Шесть документов доступны для чтения в модальном окне и скачивания в TXT. Неработающих PDF-ссылок нет.
- FAQ через Bootstrap Accordion, мобильное меню Collapse, активная навигация и хлебные крошки.
- Семантическая разметка, подписи и ошибки полей, skip-link, видимый фокус, закрытие окон клавишей Escape и возврат фокуса к вызвавшей кнопке.

## Редактирование

Курсы меняются в массиве `window.trainingCourses` в `assets/js/courses.js`. Это единый источник данных для каталога, популярных курсов и выбранной программы в форме.

Все страницы можно редактировать непосредственно. Для согласованного изменения общей шапки, подвала, форм и документов предусмотрен необязательный скрипт:

```shell
node tools/build-pages.cjs
```

**Он перезаписывает пять HTML-файлов и шесть TXT-документов** из шаблонов в `tools/build-pages.cjs`. Если меняете HTML вручную, не запускайте генератор без переноса изменений в его шаблоны. Для просмотра сайта генератор запускать не нужно.

## Изображения

Шесть фотографий созданы инструментом генерации изображений специально для проекта: мастерская, сварка, электромонтаж, слесарные работы, строповка и занятие с преподавателем. Это иллюстрации, а не реальные фотографии организации. Локальные WebP имеют размер 1200×800 px и занимают около 100–135 КБ каждый. Точные запросы сохранены рядом в `*.prompt.txt`; `*.webp.json` содержат сведения о происхождении для Impeccable.

Фотографии не содержат текстовых блоков сайта. Favicon и интерфейсные пиктограммы относятся к Bootstrap Icons; SVG не используется для иллюстраций.

## Проверка

Результаты и ограничения проверки описаны в `.impeccable/review/AUDIT.md`. Автоматизированный отчет — `.impeccable/review/checks.json`, снимки страниц — в той же папке. Проверяются все пять страниц на ширинах 375, 768, 1024 и 1440 px, локальные ссылки и ресурсы, каталог, модальные окна, FAQ, формы и мобильное меню.

Для повторения проверки нужен отдельно установленный Playwright и Chrome. Это инструменты разработки, а не зависимости сайта:

```shell
node tools/check-site.cjs
```

Если Playwright установлен вне проекта, укажите путь к пакету через переменную `PLAYWRIGHT_PATH`. Перед проверкой запустите локальный сервер на порту 4173. Проверка доступности использует локальную библиотеку axe-core 4.10.3. Автоматические проверки не заменяют полную ручную проверку со скринридером.

## Демонстрационные данные

Название, адрес, телефон, email, программы, сроки и стоимость условные. Адрес не отмечен на реальной карте. Действующая лицензия, аккредитация, награды, отзывы и юридические реквизиты не заявляются. Образцы документов не являются готовыми юридическими документами.

Формы не вызывают `fetch`, не отправляют письма и не сохраняют персональные данные в cookies, localStorage или базе данных. Данные проверяются только в браузере. Для тестирования используйте вымышленные значения. Перед реальным запуском потребуются настоящие сведения об организации, проверенные программы и документы, backend для заявок и политика, соответствующая реальной обработке данных.
