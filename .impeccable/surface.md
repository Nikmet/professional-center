# Bootstrap Corporate — учебный центр

## Direction contract
Пользователь закрепил традиционный корпоративный стиль и поручил самостоятельную реализацию. Кодовая реализация следует точному заданию, без альтернативных концепций. Результат concept-seed 50b22333 не меняет закрепленные пользователем стиль, палитру, сетку и состав страниц.

## First viewport
Белая шапка с логотипом-книгой, темно-синяя контактная панель, светлая Bootstrap Navbar. Слева заголовок 38 px и две кнопки, справа фотография производственного занятия. Никаких декоративных эффектов и вымышленных доказательств надежности.

## Visitor path
Каталог → поиск или направление → подробности выбранной программы → заполненная тема заявки. На информационных страницах breadcrumbs и четкие переходы к курсам и связи.

## Interaction
Фильтры обновляют количество программ и пустое состояние. Bootstrap Modal показывает содержание выбранного курса; его идентификатор переносится в форму. Невалидная форма фокусирует первое проблемное поле, валидная честно сообщает об отсутствии отправки.

## Responsive
375, 768, 1024, 1440 px. Collapse до lg, карточки 1/2/3 колонки, направления 1/2/4 колонки. Изображения без текста, локальные WebP. Проверка без изменения заданной концепции.
